Seção 2 - Ranking de Tecnologias

  1. HTML

    Linguagem responsável pela estrutura das páginas web.

  2. HTTP

    Protocolo utilizado para a comunicação na Web.

  3. URL

    Endereço utilizado para acessar recursos na Internet.

  4. DNS

    Traduz nomes de domínio em endereços IP.

  5. API

    Permite a comunicação entre diferentes sistemas.

Seção 3 - Glossário de Termos Técnicos

HTML
Linguagem de marcação para criar páginas web.
Define a estrutura do conteúdo.
DOM
Representação da estrutura de uma página.
Pode ser acessado e manipulado pelos navegadores.
HTTP
Protocolo de transferência de dados da Web.
URL
Endereço Web
Localização de um recurso na Internet.
DNS
Sistema de Nomes de Domínio
Converte nomes de domínio em endereços IP.
Servidor
Computador que fornece serviços ou páginas aos usuários.
Navegador
Programa utilizado para acessar páginas da Internet.
API
Interface de comunicação entre sistemas.
